## 🏷️ 브랜드 정의 (확정)
- **회사/모브랜드: 공간f5** — **본업 = 인테리어(채움).** "공간을 **새로고침(F5)** 하다"
  - **F5 = 비움 + 채움** → 네모맨(철거)이 비우고, 공간f5(인테리어)가 새로 채운다
- **서브브랜드: 네모맨** = 공간f5의 **철거(비움)** 부문 (마스코트 겸)
- **브랜드 구조:** `공간f5 (인테리어·본업) ▸ 네모맨 (철거·진입점)`
- **핵심 전략:** 정부지원 철거(네모맨)로 리드 확보 → 리뉴얼·신규 고객은 **인테리어(공간f5)로 크로스셀**
- **이 사이트의 초점:** 네모맨(철거) + 정부지원 → **인테리어로 연결하는 다리** 포함
- **슬로건: "비움에도 기술이 있습니다."** *(잠정, 조정 가능)*
- **캐릭터/마스코트: 네모맨** (파란 작업복, 사용자 제작 완료)
- **컬러(네모맨 기반):** 코발트 블루 + 옐로우 + 딥네이비 + 오프화이트 (참고 사이트와 차별화)

## ⚠️ 법적 주의사항 (반드시 지킬 것)

### ✅ 따라 해도 되는 것
- 사업 모델·아이디어 (정부지원 연계 철거 매칭 컨셉)
- 사이트 구조·페이지 구성 (소개/정부지원/시공사례/협력사/견적신청)
- 일반적인 UI 패턴 (히어로, 프로세스, 강점 나열, 자가진단, 폼, 플로팅 CTA)
- 기능 (견적 폼, 협력사 모집 폼)

### ❌ 따라 하면 안 되는 것
1. **브랜드 아이덴티티** — "철거의고수", 마스코트 "철수", 로고 (상표등록 제40-2469949호) → 비슷하게도 금지
2. **창작물 그대로 복사** — 일러스트·사진·광고 문구 복붙, HTML/CSS 코드 복사 → 전부 새로 작성
3. **남의 콘텐츠를 내 것처럼** — 후기·시공사례·실적 통계(1,513건 등)·협력사명·회사정보 → 거짓광고(표시광고법) 위반

### ⚠️ 업종 특성상 추가 주의
- 정부지원 제도(희망리턴패키지 / 소상공인시장진흥공단) 정보는 **실제 제도대로 정확하게**
- 폼으로 개인정보 수집 시 → **본인 명의 개인정보처리방침 + 수집 동의** 필요
- 실적/후기는 **실제 데이터만** (없으면 "준비중" 처리, 가짜 금지)

## 📋 작업 순서

### STEP 0 — 방향 확정 (빌드 전 결정)
- [ ] **기술 스택**: 정적 HTML/CSS/JS *(추천)* ↔ React/Next  ← **남은 결정 1개**
- [x] **브랜드**: ✅ **네모맨** (브랜드명 = 마스코트)
- [x] **회사명**: ✅ **공간f5**
- [ ] **회사 상세정보(전화·주소·사업자번호)**: "준비중" placeholder로 시작 *(추천)*
- [x] **마스코트/캐릭터**: ✅ **네모맨** 제작 완료 (사용자 제공)

### STEP 1 — 디자인 기반 (뼈대)
- [ ] 색상·폰트·버튼 스타일 정의 (화이트 + 포인트 컬러)
- [ ] 공통 **헤더(GNB)** 제작
- [ ] 공통 **푸터** 제작
- [ ] 우측 **플로팅 CTA**(빠른견적 / 협력사입점 / 전화) 제작

### STEP 2 — 홈 / 소개 페이지 `index` ⭐ 시안 확정

- [ ] 실적 통계 (placeholder)
- [ ] CTA
- [ ] 👉 **여기서 디자인 톤 확정 → 이후 페이지 동일 틀로 복제**

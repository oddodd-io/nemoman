## 1. 프로젝트 개요

### 배경
- 폐업 소상공인 증가 → 임대차 **원상복구 의무**로 철거·복구 비용(수백만 원) 부담.
- 정부(소상공인시장진흥공단) **희망리턴패키지 '점포철거비 지원'** 제도가 있으나 **모르는** 사람이 많음.
- 철거 시장은 견적 편차가 크고 불투명 → **업체 불신** + "얼마 나올지 모름"이 가장 큰 장벽.

### 목적
폐업이라는 힘든 순간에 **"내가 대상인지 · 얼마인지"를 즉시 알려주고**, 신뢰할 수 있는 철거로 연결하며,
정부지원까지 원스톱으로 마무리 → 공간f5는 **검증된 리드**를 확보한다.

### 핵심 목표
1차(고객) 견적/상담 리드 · 2차(공급) 협력사 모집 · 브랜드화로 **"공간 솔루션 회사"** 인식.

## 2. 차별화 전략 (vs 레퍼런스) ⭐

레퍼런스(철거의고수)는 **"콜드 견적 폼 1개"** 퍼널. 공간f5는 네 가지로 앞선다.

| 축 | 레퍼런스 | 공간f5 · 네모맨 |
|---|---|---|
| **진입 문턱** | 견적 폼 하나 | **자가진단 + 비용계산기**로 "대상·금액"을 즉답, 리드를 데움 |
| **신뢰 확보** | 후기·실적 의존(초기 불가) | **정보센터·투명 견적·정부 공식연계·명확한 약속**으로 대체 |
| **유입 채널** | 광고 의존 | **콘텐츠 SEO(가이드)** 로 검색 유입 추가 |
| **정체성** | 철거 매칭업체 | **공간 솔루션 브랜드**(F5=새로고침 서사) |

> 핵심 한 방: **비용계산기** — 방문자가 이탈하기 전에 "얼마 나올지"를 투명하게 보여주는 것이 이 사이트의 시그니처.

## 3. 문제 정의 & 시장

| 고객이 겪는 문제 | 우리의 해결 |
|---|---|
| 철거·복구 비용이 부담된다 | 정부지원(최대 250만원) 연계 |
| **얼마 나올지 감이 안 온다** | **비용계산기로 예상 범위 즉시 제공** |
| 내가 지원 대상인지 모른다 | **자가진단** 도구 |
| 어느 업체를 믿을지 모른다 | 검증된 협력사·투명 견적·하자 A/S |
| 폐업 절차·정산이 복잡하다 | 상담→견적→시공→정산 원스톱 |
| 정보가 흩어져 있다 | **정보센터(가이드)** 한 곳에 정리 |

## 4. 타깃 사용자 (페르소나)

### 1차 · 폐업 예정 소상공인 (핵심)
- 50대 자영업자, 8년 운영 점포를 임대 만료·매출 부진으로 폐업 예정.
- 원상복구 의무로 철거 견적 탐색 중, 비용 부담·업체 불신·정보 부족.
- **모바일 검색.** 원하는 것: **얼마인지 · 지원 대상인지 · 믿을 업체.**

### 2차 · 철거 협력사 (공급)
- 영업·마케팅 인력 없이 일감 불안정한 중소 철거업체.
- 원하는 것: 안정적 일감·마케팅 비용 절감·브랜드 신뢰.

## 5. 브랜드 전략

### 브랜드 아키텍처 — 모브랜드(인테리어) ▸ 서브브랜드(철거)
| 레이어 | 이름 | 정체 |
|---|---|---|
| 모브랜드/회사 | **공간f5** | **본업 = 인테리어(채움).** "공간을 새로고침(F5)하다" |
| 서브브랜드 | **네모맨** | **철거(비움)** 부문 · 마스코트 겸 |
| 슬로건 | **"비움에도 기술이 있습니다"** | 전문성·신뢰 |

> **F5 = 비움 + 채움.** 네모맨(철거)이 비우고, 공간f5(인테리어)가 새로 채운다 → 공간 새로고침 완성.

### 철거 → 인테리어 크로스셀 (핵심 사업 논리)
- **철거는 인테리어의 첫 단계이자 진입점.** 정부지원 철거로 리드를 모으고, 그중 리뉴얼·업종변경·신규 입점 고객을 **인테리어(공간f5)로 전환** → 철거는 진입점, 인테리어가 본 수익.
- 이 사이트(네모맨)는 두 고객을 받아 분기:
  1. **폐업 철거** → 정부지원 + 철거 완결
  2. **리뉴얼/신규 철거** → 철거 + **인테리어 연결(고가치 리드)**

### 톤 & 매너
- 공감적이되 무겁지 않게 — 폐업은 실패가 아니라 **새로고침(F5)**.
- 전문적이되 친근하게 — 네모맨이 딱딱함 완화.
- 키워드: *새로고침·비움·기술·안심·마무리·새출발.*

### 마스코트 활용
- 히어로/프로세스/강점/후기 등에 네모맨 포즈(든든/깔끔/철저/새출발).
- 로고 락업: `공간f5` 워드마크 + 네모맨 심볼.

## 6. 핵심 가치 제안 (USP)

1. **정부지원 최대 250만원 연계** + 자가진단으로 자격 즉시 확인
2. **비용계산기** — "얼마 나올지" 미리 투명하게
3. **믿을 수 있는 시공** — 검증 협력사·하자 A/S·추가비용 없는 투명 견적
4. **폐업 원스톱** — 철거·원상복구·폐기물·정부지원 대행까지 (솔루션 회사)
5. **정보센터** — 폐업/지원/철거 궁금증을 한 곳에서

## 10. 핵심 기능 명세

### 10-1. 비용계산기 ⭐ (신규)
- 입력: 건물유형 · 업종 · 평수 · 철거범위(부분/전체) · (옵션)폐기물량
- 출력: **예상 견적 범위**(최소~최대) + 정부지원 대상 시 **예상 자기부담금**
- 고지: "예상·참고용이며 실제 금액은 현장실사 후 확정"
- 목적: 이탈 전 즉답 → 신뢰 → 견적 폼으로 자연 연결(입력값 이월)

### 10-2. 자가진단 (정부지원 자격)
- 제외요건 6문항 예/아니오 → 하나라도 "예"면 불가 안내 / 모두 "아니오"면 가능→견적 연결
- "최종 자격은 공단 심사" 고지

### 10-3. 빠른 견적신청 폼
- 필수: 이름·연락처·지역·건물유형·업종·평수·철거범위 + **개인정보 동의**
- 선택: 희망 시공일·요청사항 / 계산기 값 자동 이월
- **인테리어 관심 여부**(철거 후 인테리어 계획?) → "예"면 **인테리어 리드로 분기(공간f5 크로스셀)**
- 제출 → 저장·알림 → 완료 안내

### 10-4. 협력사 신청 폼
- 업체명·담당자·핸드폰·사업자등록증(첨부)·소재지·시공가능지역·사업구분(다중)·실사인력·소개 + **동의(제3자 제공)**

### 10-5. 공통 UI
- 우측 플로팅 CTA · 헤더 전화 tel: 연결 · 반응형(모바일 우선)

## 12. 신뢰 설계 — 실적 없이 ⭐ (신규)

초기엔 후기·실적이 없다. 대신 아래로 신뢰를 만든다(전부 합법·사실 기반).
1. **정부지원 공식 제도 연계** — 신뢰 차용
2. **투명 견적 + 비용계산기** — 예측 가능성
3. **명확한 약속** — 하자 A/S · 추가비용 없음 · 안전(에스크로) 결제
4. **프로세스 전면 공개** — 상담→견적→시공→정산
5. **회사·연락처 투명 공개** — 실재하는 사업자
6. **FAQ** — 불안 선제 해소
7. (실적 쌓이면) 사례·후기 추가 — **가짜 절대 금지**

# 네모맨 · 공간f5 웹사이트 — 디자인 브리프 (Kimi AI용)

> **사용법:** 이 문서 전체를 Kimi AI에 붙여넣고, **네모맨 캐릭터 이미지를 함께 업로드**하세요.
> 그다음 *"이 브리프대로, 홈페이지부터 반응형 HTML/CSS(+바닐라 JS)로 만들어줘"* 로 시작하면 됩니다.

## 1. 한 줄 요약
폐업·리뉴얼 소상공인을 위한 **철거 매칭 + 정부지원 안내 랜딩 사이트.** 목표는 **견적/상담 신청(리드) 수집.**

## 2. 브랜드
- **회사(모브랜드): 공간f5** — 본업은 **인테리어**. 뜻: "공간을 **새로고침(F5)** 하다"
- **이 사이트 브랜드: 네모맨** — 공간f5의 **철거** 부문 + 마스코트
- **슬로건: "비움에도 기술이 있습니다."**
- **컨셉:** F5(새로고침) = **비움(철거·네모맨) + 채움(인테리어·공간f5)**
- **이 사이트 범위:** **철거(네모맨) 중심** + 인테리어(공간f5)로 가는 **연결 다리** 포함

## 3. 디자인 방향
- **무드:** 친근하지만 전문적, 신뢰감. 폐업의 무거움을 밝고 희망차게(새로고침).
- **레이아웃:** 깔끔 · 넉넉한 여백 · 카드형 · 큼직한 라운드 CTA · 섹션마다 네모맨 일러스트.
- **반응형: 모바일 우선.** 전화번호는 `tel:` 링크로.

## 4. 공통 요소 (전 페이지)
- **헤더:** 로고(공간f5·네모맨) + 메뉴(정부지원 / 간편견적 / 시공사례 / 협력사) + `[무료 견적]` 버튼 + ☎ 전화
- **우측 플로팅 버튼(고정):** 간편견적 · 협력사 입점 · ☎ 전화
- **푸터:** 회사정보(상호 **공간f5**, 대표·사업자번호·주소 = "준비중") · 이용약관 · 개인정보처리방침 · 운영시간

## 5. 페이지별 구성 (MVP)

**① 홈**
히어로(네모맨 + 슬로건 + CTA 3종: 자가진단/간편견적/전화) → "폐업, 이런 고민이시죠?" 공감 → 정부지원 배너(최대 250만원) → **비용계산기 티저** → 네모맨이 하는 일(철거·원상복구·폐기물·정부지원 대행) → 🔗 **"철거 후 인테리어까지 — 공간f5"** 브리지 → 프로세스(상담→견적→시공→정산) → 강점 6가지 → 시공사례 미리보기 → FAQ 미리보기 → 최종 CTA

**② 정부지원 + 자가진단**
제도 소개(희망리턴패키지) → 지원 안내(최대 250만원) → **자가진단**(6문항 예/아니오 → 가능/불가) → 진행절차 7단계 → CTA

**③ 간편견적 + 비용계산기 ⭐ (핵심)**
**비용계산기**(건물유형·업종·평수·철거범위 → 예상 견적 범위) → **견적신청 폼**(연락처 등 + 인테리어 관심 여부) → 완료 안내

**④ 시공사례**
사례 카드(업종·지역·평수·견적·기간·후기). *초기엔 "준비중"/예시 명시.*

**⑤ 협력사 모집**
혜택 4가지 → 신청 폼(업체명·담당자·연락처·지역·사업구분 다중선택·동의)

**⑥ FAQ**
정부지원 / 비용 / 시공 / 절차 카테고리
